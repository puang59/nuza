**Typing that follows the conventions you already know, a file tree that works like an explorer, and smooth motion on high-refresh screens.**

## New

- **Type `[[` to link a note.** A list of the notes in your vault opens and narrows as you type. Choosing one fills in its name and steps past the closing brackets.
- **Pick several files at once** in the sidebar: mod-click adds or removes a file, and shift-click (or shift and an arrow key) takes in a range. Drag them together, or delete them with one question.
- **Cut, copy and paste files** in the sidebar with mod+X, mod+C and mod+V, or from the right-click menu. Pasting a copy beside the original makes a numbered duplicate.
- **F2 renames** the selected file or folder, and **Delete** or **mod+Backspace** deletes it.
- **New File makes folders on the way:** `journal/2026/today` creates `journal` and `2026` if they are not there yet, then the note.
- **A file named without an extension is a note:** New File `ideas` makes `ideas.md`.
- **Drop a file onto another file** to move it into that file's folder. A closed folder opens when you hold a dragged file over it.
- **Wrap a selection** by typing `*`, `_`, `` ` ``, `~`, `=` or a quote over it, instead of replacing it.
- **Paste a link over selected text** to turn the text into a link.
- **Vim's `o` and `O`** continue a list, a task list or a quote the way Enter does.

## Fixed

- **Smooth on 120Hz and 144Hz displays.** Scrolling, the caret and panels sliding in were drawn at half the screen's refresh rate.
- **Opening the AI panel or the sidebar no longer makes the text jitter.** The note re-wraps once instead of on every frame of the slide.
- **Leaving a list or a quote with Enter** now leaves a blank line, so what you type next is no longer drawn indented under the last point or inside the quote.
- **Enter on a sentence written under a list** carries on as a sentence instead of starting a bullet.
- **Enter after an HTML tag** no longer indents the next line.
- **Clicking into a paragraph no longer unfolds every link in it.** A link's address only shows when the caret reaches that link.
- **Quotes no longer pair themselves** while you write. Brackets still do, and code blocks are unchanged.
- **Tab in a paragraph** no longer turns it into a code block.
- **Enter at the start of a point under a paragraph** no longer turns the paragraph into a heading.
- **Vim's block cursor** follows your accent colour, and no longer leaves an empty box behind when the editor loses focus.
